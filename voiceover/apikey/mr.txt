ए आय शिक्षामित्रचे AI फीचर्स वापरण्यासाठी तुमची स्वतःची फ्री API key हवी. हे एकदाच करायचं सेटअप आहे, चला सोबत करूया.

API key म्हणजे Google च्या AI चा तुमचा वैयक्तिक पास. यामुळेच चॅट, टूल्स आणि प्रश्नपत्रिका फीचर्स चालतात.

आणि हे पूर्णपणे मोफत आहे. ना कार्ड, ना पेमेंट.

ॲपमध्ये More वर टॅप करा, मग Your API key, आणि Google AI Studio ची लिंक उघडा.

तुमच्या Google अकाउंटने साइन इन करा, आणि Create API key दाबा.

प्रोजेक्ट निवडा. प्रोजेक्ट नसेल, तर नवीन प्रोजेक्ट तयार करा, कोणतंही नाव द्या, आणि तो निवडा.

Create key दाबा, आणि तुमची key कॉपी करा.

पुन्हा ॲपमध्ये, कन्फर्मेशनवर टिक करा, key पेस्ट करा, आणि Save दाबा.

तुमची key फक्त तुमच्या डिव्हाइसवरच राहते, क्लाउडवर सिंक होत नाही.

रोजच्या कामासाठी फ्री key पुरेशी आहे. जास्त हवं असेल, तर कधीही Google चा पेड प्लॅन घेऊ शकता.
