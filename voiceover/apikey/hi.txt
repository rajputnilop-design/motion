ए आई शिक्षामित्र के AI फ़ीचर्स के लिए आपको अपनी फ़्री API key चाहिए। ये एक बार का सेटअप है, चलिए साथ मिलकर करते हैं।

API key, Google के AI तक पहुँचने का आपका पर्सनल पास है। इसी से चैट, टूल्स और पेपर बनाना काम करता है।

और ये बिल्कुल फ़्री है। न कार्ड, न कोई पेमेंट।

ऐप में More पर टैप कीजिए, फिर Your API key, और Google AI Studio का लिंक खोलिए।

अपने Google अकाउंट से साइन इन कीजिए, और Create API key दबाइए।

प्रोजेक्ट चुनिए। प्रोजेक्ट नहीं है, तो नया प्रोजेक्ट बनाइए, कोई भी नाम दीजिए, और उसे चुन लीजिए।

Create key दबाइए, और अपनी key कॉपी कर लीजिए।

वापस ऐप में, कन्फ़र्मेशन पर टिक कीजिए, key पेस्ट कीजिए, और Save दबाइए।

आपकी key सिर्फ़ आपके डिवाइस पर रहती है, क्लाउड में सिंक नहीं होती।

रोज़ के काम के लिए फ़्री key काफ़ी है। ज़्यादा चाहिए, तो कभी भी Google का पेड प्लान ले सकते हैं।
